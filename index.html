MCHOSE Configurator

Configure an A7 V2 mouse and talk to an Ace 68 keyboard from your browser, without the M HUB site.

This browser has no WebHID. Use Chrome, Edge, Opera or another Chromium browser, and open the page over https:// or http://localhost.

Ace 68

Settings for the Ace 68 aren't supported yet. MCHOSE hasn't published how the Ace 68 is configured, and nobody has documented it yet. Sending made-up commands to a keyboard can leave it in a bad state, so this page doesn't guess. It identifies the keyboard, shows its HID interfaces and every report it sends, and lets you record what the official site does (see Capture the protocol). One recording gives enough to add actuation, rapid trigger, lighting and remapping here.

Capture the protocol from the official site

      
    
        
  1. Open the official MCHOSE M HUB web driver in Chrome or Edge. Don't connect the keyboard yet. If it connects on its own, unplug and replug the keyboard after step 3.
    2. 
        
  2. Press F12, open the Console, paste the contents of tools/capture-mhub.js and press Enter.
    3. 
        
  3. Connect the keyboard in M HUB. Before each change, run mchoseCapture.mark('what you are about to change'), then make that one change.
    4. 
        
  4. Run mchoseCapture.download() and add the JSON file to this repository under captures/.
    5. 
      

      
The script only records the traffic and passes every call through unchanged.
