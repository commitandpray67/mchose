MCHOSE Configurator

Configure an A7 V2 mouse and talk to an Ace 68 keyboard from your browser, without the M HUB site.

This browser has no WebHID. Use Chrome, Edge, Opera or another Chromium browser, and open the page over https:// or http://localhost.

Ace 68

Keyboard settings aren't supported yet. MCHOSE hasn't published how its Ace keyboards are configured, and nobody has documented it yet. Sending made-up commands to a keyboard can leave it in a bad state, so this page doesn't guess. It identifies the keyboard, shows its HID interfaces and every report it sends, and lets you record what the official site does (see Record the keyboard protocol). One recording gives enough to add actuation, rapid trigger, lighting and remapping here.

Record the keyboard protocol from the official site

      
    
        
  1. Close this page's keyboard connection (Disconnect above), so only M HUB talks to the keyboard.
    2. 
        
  2. Open the official MCHOSE M HUB web driver in Chrome or Edge, in a new tab.
    3. 
        
  3. Click  here.
    4. 
        
  4. In the M HUB tab, press F12 and open the Console tab. Paste (Ctrl+V) and press Enter.
          If Chrome warns about pasting, type allow pasting, press Enter, then paste again.
          You should see 'mchoseCapture installed…'. To check later, type mchoseCapture and press Enter: it should show an object, not "not defined".
    5. 
        
  5. Connect or select the keyboard in M HUB. Then, for each setting you want here, type a label in the Console and press Enter, then make that one change in M HUB. For example:
          
    mchoseCapture.mark('actuation all keys 2.0 -> 1.0 mm')
mchoseCapture.mark('rapid trigger on')
mchoseCapture.mark('rapid trigger sensitivity 0.3 -> 0.1')
mchoseCapture.mark('lighting effect static, red')
mchoseCapture.mark('brightness max -> min')
mchoseCapture.mark('remap CapsLock -> Ctrl')
mchoseCapture.mark('polling rate 1000 -> 8000')
    
          Change one thing at a time, and use values you can recognise (going from one extreme to the other helps).
    6. 
        
  6. Type mchoseCapture.download() and press Enter. A mchose-capture-….json file is saved to your Downloads. Send that file.
    7. 
      

      

        Can't copy? Select the script here
        
      

      
The script only records the traffic and passes every call through unchanged. Reloading the M HUB tab removes it.
